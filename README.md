# Гайд по Git от новичка для новичка ":)"

## Надеюсь ты уже разобрался как установить Git и "Git Bash", я же расскажу тебе как создать репозиторий или скопировать его у других через "Fork",
 научу коммитить и заливать проект в свой профиль git.

## Итак, начнём с создания репозитория, для этого ты можешь ввести в "Git Bash" команду `mkdir` (make directory или создать папку), назови её как пожелаешь.

## Далее ты можешь создать новые папки внутри проекта с помошью команды `mkdir`, чтобы добавить файл в папку - перейди в нужную дирректорию
 командой `cd %НАЗВАНИЕ ПАПКИ%` и введи команду `touch test.txt`, где "test" - это название файла, ты можешь назвать его как угодно, 
  а ".txt" - расширение, которое поддерживает файл.

## Когда ты будешь готов поделиться своим проектом - перейди в свой профиль git и дальше мне лень писать...
